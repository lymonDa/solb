## 1. Keyword Strategy Principles

1. **High Commercial Intent**: Target users actively seeking field execution (contractors, homeowners, MEP engineers, interior fit-out companies) in Riyadh.
2. **Intent Cannibalization Prevention**: Strictly map each keyword cluster to one canonical page. The homepage serves umbrella queries; specific service pages capture high-intent service-specific demand.
3. **Saudi Arabic Local Dialect & Technical Terms**: In Saudi Arabia, both standard Arabic («قص وتخريم الخرسانة») and colloquial technical terms («تخريم كور», «قص دايموند», «منشار ليزر/جداري») are searched. We integrate both naturally into body copy and FAQs without keyword stuffing.
4. **No Doorway Pages**: We do not create duplicate thin pages per neighborhood (e.g., "قص خرسانة في النرجس", "قص خرسانة في الياسمين"). Instead, the Riyadh service area covers all municipal districts naturally.

## 4. Google Ads Negative Keyword Candidates

To protect campaign budget and prevent unqualified clicks in Riyadh, the following negative keyword list must be implemented at the campaign level:

### Arabic Negative Keywords
- **وظائف / توظيف / رواتب** (Jobs, hiring, salary inquiries)
- **شراء منشار / معدات للبيع / حراج** (Buying tools, used machinery on Haraj, equipment for sale)
- **إيجار بدون عامل / تأجير معدات** (Equipment rental without operators)
- **تدريب / دورة / يوتيوب** (Training courses, DIY tutorials, videos)
- **مجاناً / مجاني** (Free services)
- **جدة / الدمام / مكة / المدينة / أبها** (Cities outside our verified operational zone of Riyadh)

### English Negative Keywords
- **Jobs / Career / Vacancy / Salary**
- **Machine for sale / Buy diamond blade / Used core drill**
- **Rental without operator / Tool hire only**
- **DIY / How to / Tutorial / Course**
- **Free / Torrent / PDF download**
- **Jeddah / Dammam / Khobar / Dubai / Qatar** (Outside Riyadh service boundary)
